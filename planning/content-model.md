# Content model

## Alert card

- Alert ID
- Title and severity
- Affected object
- Trigger rule
- Period and freshness
- Value at risk
- Confidence and limitations
- Responsible person
- SLA and escalation status
- Primary action

## KPI card

- KPI ID and name
- Current value
- Target and threshold
- Trend
- Unit and granularity
- Source and last update
- Definition and formula link
- Authorized drill-down
