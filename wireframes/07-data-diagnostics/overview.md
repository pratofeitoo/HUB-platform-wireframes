# SCR-07 — Data Diagnostics

## Purpose

Make source health, integration freshness, rejected records, data quality, and KPI lineage observable.

## First viewport

- Source health summary.
- Job status and last run.
- Freshness and rejection indicators.
- Quality exceptions.
- Critical KPI lineage.

## Primary actions

Open source, inspect job, review rejection, reprocess, export rejection, and inspect lineage.

## Guardrail

Errors must never be silent. Reprocessing must preserve history and audit events.
