# SCR-05 — Alerts and Decisions Center

## Purpose

Turn governed signals into contextualized, human-owned decisions and actions.

## First viewport

- Alert queue grouped by severity and SLA.
- Status, owner, affected object, and value-at-risk columns.
- Explanation and action affordances.

## Primary actions

Assume, explain, add context, decide, create action, escalate, suppress, and close.

## Required explanation

Source data, rule, period, confidence, limitations, and contestation path.

## Traceability

`SCR-05`, `ALT-01..08`, `BL-010`, `BL-011`, `GOV-05`, `GOV-06`, `GOV-09`.
