# WF-02B — Manager alert entry detail

## Purpose

Provide enough context for the manager to review a signal before deciding whether action is appropriate.

## Content

- Alert ID, title, severity, status, and SLA.
- Affected team, person, project, or client within authorized scope.
- Trigger rule and threshold.
- Relevant time window and source freshness.
- Related KPI trend.
- Context request and existing comments.
- Links to explanation, decision, and action.

## Actions

Add context, assume alert, record decision, create action, escalate, suppress, or close.
