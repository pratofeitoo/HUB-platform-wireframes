# SCR-02 — Manager Dashboard

## Purpose

Help a manager understand team goals, capacity, performance, alerts, and active actions within the authorized hierarchy.

## First viewport

- Team and period scope.
- Goal attainment and capacity cards.
- Alerts requiring context or action.
- Action-plan progress.

## Primary actions

Open alert, add context, create action, revise goal, assign owner, and track SLA.

## Guardrail

Do not infer cause from a score. Ask for context and expose the relevant evidence.

## Traceability

`SCR-02`, `BL-012`, `MOD-02`.
