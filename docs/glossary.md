# Glossary

| Term | Meaning |
|---|---|
| Canonical source | Authoritative source kept in the Obsidian vault. |
| Derived extract | Data copied or transformed from a canonical source. |
| Screen | A destination or route in the platform experience. |
| State | A condition of a screen, such as loading, empty, stale, error, or denied. |
| Alert | A governed signal generated by a rule and requiring human context or action. |
| Decision | A human-recorded response to an alert or recommendation. |
| Validated value | Financial value reviewed and approved by Finance with evidence. |
| Tenant | An isolated organization or customer context. |
| Lineage | Traceability from a displayed value to its source, transformation, and KPI definition. |
