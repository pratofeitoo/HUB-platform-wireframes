# Working agreements

- Keep canonical source files and experimental design work separate.
- Label proposed, illustrative, validated, rejected, and approved material.
- Use synthetic data only in the prototype.
- Never imply that correlation establishes causation.
- Make permissions, data freshness, source lineage, explainability, and auditability visible.
- Preserve human review for consequential decisions.
- Record material changes in `decisions/decision-log.md`.
