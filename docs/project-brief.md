# Project brief

## Objective

Map the HUB platform's screens, role-based navigation, core journeys, states, and traceability before producing an interactive wireframe prototype.

## Initial scope

Prioritize the MVP flow:

`Executive Cockpit → Manager Dashboard → Alert Detail → Decision/Action → ROI Validation`

The supplier marketplace and future academic/community capabilities remain outside the first wireframe pass unless explicitly pulled into scope.

## Working status

This is a provisional design workspace. Promotion to an approved interface specification requires review against the canonical technical source and validation with Product, Data, RH, Finance, Security/LGPD, and the Monks pilot.
