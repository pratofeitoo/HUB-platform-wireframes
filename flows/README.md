# Flows

End-to-end journeys connecting screens, actions, decisions, governance checks, and measurable outcomes.

All flow documents use the same provisional structure:

1. User and goal.
2. Entry point.
3. Meaningful screen and action steps.
4. Decision and error branches.
5. Permission, tenant, hierarchy, consent, and LGPD checks.
6. Endpoint or success condition.
7. Audit events.
8. Validation criteria.

These are textual user-flow specifications, not approved production workflows or visual FigJam diagrams. The canonical technical plan and workbook remain authoritative.
