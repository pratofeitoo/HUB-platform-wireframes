# Design principles

1. **Make the signal actionable.** Every important metric leads to context, explanation, and a next step.
2. **Show evidence and uncertainty.** Source, freshness, confidence, limits, and assumptions remain visible.
3. **Protect the person.** Minimize sensitive data and preserve contestation and human review.
4. **Use progressive disclosure.** Keep overview screens calm; reveal detail when the user asks for it.
5. **Keep value traceable.** Estimated, influenced, validated, and realized value must not be conflated.
6. **Design for role clarity.** Navigation and actions follow the user's responsibility and authorized scope.
