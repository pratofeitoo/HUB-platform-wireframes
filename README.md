# HUB Platform Wireframes

Standalone workspace for screen mapping, UX flows, wireframes, design-system work, and prototype development for the HUB platform.

The Obsidian vault remains the canonical source and governance space. This workspace contains derived, provisional, proposed, validated, and implementation-oriented design material.

## Source boundary

Canonical source files remain in the HUB Obsidian vault. See [`sources/source-register.md`](sources/source-register.md) before using or updating derived data.

## Workspace areas

- `sources/` — source references, snapshots, and extracted data.
- `planning/` — screen map, navigation, roles, flows, states, and traceability.
- `decisions/` — assumptions, decisions, validation, and ADRs.
- `wireframes/` — screen-by-screen design definitions.
- `flows/` — end-to-end user journeys.
- `matrices/` — structured cross-references.
- `design-system/` — tokens, components, patterns, and accessibility.
- `prototype/` — interactive prototype implementation.
- `sample-data/` — safe illustrative data for design work.
- `validation/` — research, reviews, and pilot evidence.
- `handoff/` — reviewed implementation handoff material.
- `archive/` — historical and superseded work.
